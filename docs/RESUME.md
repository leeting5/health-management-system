# 项目简历描述：个人健康管理系统

## 项目定位

一个面向个人健康管理场景的前后端分离 Web 应用，用于健康指标记录、趋势分析和健康评估，具备 JWT 鉴权、数据可视化与 AI 健康助手能力。

## 技术栈

Java 17、Spring Boot 2.7、MyBatis Plus、MySQL 8、JWT、Maven；Vue 3、Vite、Element Plus、Pinia、Vue Router、Axios、ECharts。

### 项目描述

独立设计并实现了一个前后端分离的个人健康管理系统。用户可录入身高、体重、血压、血糖、心率等指标，系统自动计算 BMI 并生成健康分级评估和趋势图；同时接入 DeepSeek 提供个性化健康建议。

### 主要工作

- 基于 Spring Boot 与 MyBatis Plus 完成后端分层架构，设计用户与健康记录模块，提供注册登录、CRUD、分页、趋势统计等 REST API。
- 使用 JWT 实现无状态认证，通过拦截器统一鉴权，并用 `@RestControllerAdvice` 和 Bean Validation 实现统一异常处理与参数校验。
- 使用 PBKDF2WithHmacSHA256 加随机盐存储密码，兼容历史 MD5 数据并支持登录后自动升级，降低敏感数据泄露风险。
- 通过环境变量外置数据库、JWT 密钥和 AI 密钥，避免敏感配置硬编码，提升可部署性与安全性。
- 使用 Vue 3、Pinia、Vue Router 和 Element Plus 构建前端，封装 Axios 请求拦截器统一携带 Token 并处理 401 跳转。
- 使用 ECharts 完成 BMI、血压、血糖、心率趋势可视化，支持 7/14/30/90 天时间范围切换和正常区间参考线。
- 编写核心工具类单元测试，覆盖健康评估计算与密码哈希逻辑，保证关键逻辑可回归。
- 设计 Redis 可选持久化的 AI 会话历史存储，并实现管理员角色与用户管理后台。
- 实现 AI 多会话管理，支持新建、选择、重命名、删除会话及历史消息持久化。
- 使用 AOP 实现管理员操作日志，并提供系统公告草稿、发布、编辑、删除能力。

### 项目亮点

- 完整的前后端分离工程实践：统一响应、异常处理、鉴权、校验、环境变量外置、单元测试。
- 结合医学健康指标与软件工程，设计 BMI、血压、血糖、心率评估规则。
- 具备真实第三方 AI 服务集成经验，处理异步 HTTP 调用、上下文管理及异常降级。
